## 四、前瞻評估 runner（`scripts/forward_eval.py`）

規則來源：手冊第 06 章、`forward-batch-1-sources.json` 的 `price_basis`。

| 規則 | 實作 |
|---|---|
| entry | cutoff 之後下一個台股交易日的**開盤價**（cutoff 為 10/30 21:00 時是 11/02，不是 10/30） |
| 持有日 | entry 當日是第 1 個持有交易日；D1 = entry 當日收盤，D5、D20 為第 5、20 個持有交易日收盤 |
| 報酬 | (exit 收盤 − entry 開盤) ÷ entry 開盤；開盤與收盤都用未還原（raw）價格 |
| 交易日曆 | 由輸入檔提供（應取自 FinMind `TaiwanStockTradingDate` 的實際交易日），程式不用「週一到週五」推算 |
| 收盤可得時間 | 交易日 17:30（組長 10/22 核定）；`as_of` 早於此時刻即為 `immature` |
| 除權息 | 窗口內有除息日只標記 `corporate_action_in_window`，raw 報酬照算，不還原 |
| 方向 | 只有 `direction` 為 up／down 才計命中；none／空值只展示；報酬剛好為 0 記 `zero_return`，不算命中也不算未命中（規約未定，待組長登記） |
| 前瞻價格不回流 Agent | 不 import agents／research_ui；輸出路徑在 `data/forward`、`fixtures`、`agents` 之下一律拒寫；`--as-of` 必須明確指定，同輸入同輸出 |

NA 原因共 8 種：`cutoff_not_reached`、`calendar_missing_entry`、`window_beyond_calendar`、`immature`、`missing_entry_open`、`missing_exit_close`、`suspended_entry`、`suspended_exit`。

測試：`tests/test_forward_eval.py` 29 項通過（合成資料，只驗規則，不代表真實股價）。我另外把程式故意改壞兩處（entry 改成 cutoff 當天、D5 少算一天），測試分別有 15 項、13 項失敗，確認測試真的會擋錯。
