## 1. 估值差距狀態

公式：d = (DCF 每股價值 − 同日收盤價) ÷ 同日收盤價

| 條件 | 狀態代碼 | 畫面文字 |
|---|---|---|
| d ≥ +15% | `below_model` | 市價低於模型估值 |
| d ≤ −15% | `above_model` | 市價高於模型估值 |
| −15% < d < +15% | `near_model` | 接近模型估值 |
| WACC、g、淨負債、流通股數、FCF 任一缺值 | `undeterminable` | 無法判定：缺 DCF 關鍵參數：（列出缺哪些） |
| TTM FCF ≤ 0（**先判斷，不執行 DCF**） | `undeterminable` | 無法判定：TTM FCF ≤ 0，5 年持平情境不適用 |
| 沒有同日收盤價 | `undeterminable` | 無法判定：沒有同日收盤價 |
| DCF 每股價值 ≤ 0（保險規則，正常情況已被上一條擋下） | `undeterminable` | 無法判定：DCF 每股價值非正 |

固定註腳：「±15% 是本專題的顯示門檻，不是經驗證的投資規則；DCF 取決於 WACC、g 與 FCF 假設。」

DCF 參數依組長 10/21 核定：WACC 9%、g 3%、FCF 基準情境 = 5 年持平於 TTM FCF；公式為 `calculate_metrics(dcf_scenario)`。畫面另附 2454 的 WACC ±1% × g ±0.5% 敏感度表。

## 2. 資料品質風險

只描述資料，不描述股價。固定註腳：「資料品質風險只代表既定資料檢查的結果；『低』不代表股價風險低。」

| 等級 | 條件 |
|---|---|
| 高 | 任一**關鍵項目**缺值或未檢查；或任何未解決的矛盾；或無法證明可得時間 |
| 中 | 沒有高風險項目，但資料標示過期，或**次要項目**缺值 |
| 低 | 所有既定檢查都已執行並通過 |
| 未評估 | 一項檢查都沒執行（缺資料永遠不會顯示成「低」） |

### 比較面板與已發布清單使用的既定檢查

| 檢查 | 關鍵／次要 | 不通過時 |
|---|---|---|
| 同日收盤價 | 關鍵 | missing → 高 |
| 連續 4 季 EPS（TTM）；任一季 `eps_source = unverified` 視同缺值 | 關鍵 | missing → 高 |
| 連續 4 季 FCF（TTM） | 關鍵 | missing → 高 |
| 淨負債 | 關鍵 | missing → 高（不以 0 代替） |
| 流通股數 | 關鍵 | missing 或非正 → 高 |
| 財報可得時間 | 關鍵 | time_unknown → 高 |
| 來源片段可追溯（存在且 sha256 相符） | 關鍵 | 不存在 → 高；hash 不符 → 矛盾 → 高 |
| 工具值與 B 快照一致（含 DCF 每股與差距） | 關鍵 | 不一致 → 矛盾 → 高 |
| 每股淨值 BVPS | 次要 | missing → 中 |
| 去年同季營收 | 次要 | missing → 中 |
| 財報新鮮度（cutoff 時最新財報公告 > 150 天） | 次要 | stale → 中 |

10/21 實際結果：2454、2379、3034、2330、2317 五檔所有檢查通過 → 資料品質風險「低」。
