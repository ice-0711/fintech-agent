## 五、六個工具與兩道防前視關卡

| 工具 | 功能 |
|---|---|
| `search_evidence` | 依關鍵字搜尋證據段落（只限 3 檔研究主體，最多 5 筆） |
| `read_evidence` | 讀取一個段落的原文（最多 1,200 字；編號格式不符一律拒絕） |
| `get_financial_snapshot` | 最新一季財務數字與 TTM |
| `get_macro_snapshot` | 總經指標（白名單：CPIAUCSL、FEDFUNDS、TAIEX） |
| `get_price_window` | 最近 1／5／20 個交易日收盤價（未還原） |
| `calculate_metrics` | 所有計算：成長率、報酬率、P/E、DCF、同業比較；必須附來源引用 |

- 回傳格式固定為 `status`、`tool`、`reason`、`data` 四個欄位；查不到回 `no_data`，不回 0。
- 每次工具呼叫限時 15 秒，逾時回 `tool_error`。
- **關卡 1**（快照程式）：公告時間晚於 cutoff 的季別、總經與證據不寫進快照。
- **關卡 2**（工具）：以「請求的 cutoff」與「快照截止時間」較早者判定，cutoff 之後的資料一律不回傳。
- TTM 必須是連續 4 個單季、且 EPS 都經過原文驗證，否則回 null 並說明原因；不以單季乘 4 推估。

出處：`agents/tools_impl.py`、`agents/calculator.py`、`agents/register_tools.py`；測試 277 項全數通過（2026-10-28）。

可引用句：
> Agent 只能透過六個白名單工具讀取凍結快照；防前視由快照產生與工具查詢兩道關卡把關，所有數值計算交由確定性計算模組執行，並以固定四欄位格式回傳結果與失敗原因。
