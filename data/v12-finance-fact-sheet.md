## 一、報表口徑規範

- 財務報表基礎：合併財務報表（Consolidated）。
- 單位：股數為百萬股；每股盈餘、每股淨值、股價為元（TWD）；其餘金額為新台幣億元。
- 自由現金流：FCF = 營業現金流（CFO）− 資本支出（CapEx，正值）。FinMind `PropertyAndPlantAndEquipment` 為負值流出，快照轉正。
- 單季 EPS 來源標籤：`mops_direct`、`finmind_quarterly`、`unverified`（data-contract 第二節第 2-1 條）。
- 淨負債（快照口徑）= 計息總負債（長期借款 + 短期借款 + 應付公司債 + 應付短期票券）− 現金及約當現金；不含租賃負債。
- 可得時間：財報＝MOPS 董事會通過財報之發言時間；股價＝交易日 17:30 +08:00。

## 七、方法事實（交 C 撰寫用；C 不判定財務正確性）

1. P/E = 基準日未還原收盤價 ÷ 連續四季 EPS 合計；EPS ≤ 0 或不足四季時不計算。
2. P/B = 基準日收盤價 ÷ 每股淨值（歸屬母公司權益 ÷ 流通股數）。
3. 同業平均只用 2379、3034；2330 為產業參照，主體 2454 也不計入平均。
4. 財報可得時間為 MOPS 董事會通過財報之發言時間，不是財報期結束日；股價以當日 17:30 為可得時間。
5. DCF 參數（WACC 9%、g 3%、5 年持平 FCF）已由組長核定為專案統一設定，但仍是程式預設、非個股風險估計；結果不得寫成目標價。
6. 缺值一律寫「無資料／無法判定」，不得以 0 代替。
